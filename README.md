* Description
Le Continent est une plateforme web développée avec Next.js permettant aux utilisateurs de :

Explorer les différentes régions du Cameroun

Découvrir des lieux touristiques emblématiques

Créer un compte et se connecter

Réserver une destination en ligne via un formulaire simple

Gérer les données via une API interne connectée à une base MySQL

L’objectif est de proposer une expérience fluide, moderne et immersive autour du tourisme camerounais.


*Fonctionnalités principales

🗺️ Exploration du Cameroun
Présentation des régions du pays

Mise en avant des paysages, cultures et lieux emblématiques

🧾 Réservation en ligne
Formulaire complet : nom, email, destination, date, nombre de personnes

Enregistrement des réservations via une API Next.js

Message de confirmation après validation

🔐 Authentification
Page d’inscription

Page de connexion

🎨 Interface moderne
Design basé sur les couleurs du Cameroun

Header et footer personnalisés

Pages stylisées et responsive

🗄️ Base de données
Connexion MySQL via mysql2

API REST interne pour gérer les réservations

*Tecnhnologies utilisée

Typescript(Typage strict)
Mysql(Base de données)
css 
Node.js(Environnement d'exécution)
